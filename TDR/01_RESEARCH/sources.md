## ⚠️ ISSUE — Библиография не соответствует стандарту TDR

**Problem:** Все 6 источников указаны как домашние страницы организаций, а не как конкретные статьи, страницы или записи с автором/годом. Ни один DOI, ни один автор, ни один год публикации не указаны.

**Why it matters:** Правило проекта (п. 15–16) требует Title, Authors, Year, Journal/Institution, DOI, URL для каждого источника. Комиссия почти наверняка задаст вопрос "на основании какого именно источника вы утверждаете X" — сейчас ответить нечем.

**Recommended solution:** Заменить каждую общую ссылку на конкретную страницу/статью:
- Лимонен → https://pubchem.ncbi.nlm.nih.gov/compound/22311 (конкретная карточка PubChem, есть точные физ-хим данные)
- RSC → конкретная статья/страница RSC про терпены или обонятельные рецепторы
- ScienceDirect → конкретная статья про steam distillation эфирных масел (нужно найти и указать DOI)

**What I need from you:** Разрешение на то, чтобы я нашёл (через веб-поиск) конкретные авторитетные страницы/статьи взамен общих ссылок, прежде чем мы продолжим writing теоретической части. DATA NOT AVAILABLE до этой замены — использовать текущие ссылки "как есть" для научных утверждений нельзя.

### ⚠️ ISSUE — экстремальные цифры первого источника не проверены
**Problem:** Цифра "рост в 2514 раз" и "0.35 μL за 6 часов" получены через WebFetch, который прогоняет контент через суммирующую модель — для таких экстраординарных чисел это ненадёжно.
**Why it matters:** Если процитировать неверную цифру в TDR, комиссия может её проверить и найти расхождение — это ударит по доверию ко всей работе.
**Recommended solution:** Не использовать точные числа из этого источника в TDR без прямой проверки полного текста статьи (открыть DOI напрямую, прочитать раздел Results). Использовать источник только для качественного вывода ("UAHD увеличивает долю лимонена и сокращает время"), не для точных цифр.
**What I need from you:** ничего срочного — просто помните при финальном writing, что эти цифры помечены как непроверенные.
