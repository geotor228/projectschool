## Тема и содержание (научная часть, реальные факты — не выдумывать заново)

**Рабочее название:** Química de les aromes i la seva extracció per destil·lació

**Research question:** Как метод экстракции — классическая гидродистилляция (аппарат Клевенджера) vs
гидродистилляция с ультразвуковой обработкой (UAHD) — влияет на выход (%) и время экстракции эфирного
масла из лепестков цветка (⟦PROVISIONAL: Rosa damascena⟧, ждём подтверждения от друга-флориста)?

**Гипотеза:** UAHD даст более высокий выход за меньшее время благодаря акустической кавитации,
разрушающей клеточные структуры (масляные железы), что облегчает высвобождение летучих соединений.

**Почему именно так (эволюция дизайна эксперимента, честно показать на сайте):**
Первая версия сравнивала разные растения (апельсин/роза/розмарин) — отклонена как ненаучная
(разные растения = разные молекулы, "лучше" ничего не доказывает). Финальная версия сравнивает
**методы** экстракции одного и того же сырья — это даёт независимую/зависимую переменную и
проверяемую гипотезу.

**Оборудование (EXP-01, раздел 10 черновика TDR):**
- Аппарат Клевенджера (колба, градуированная ловушка, обратный холодильник) — заказывается (~85-88€, Auxilab/Labotienda, Испания)
- Источник нагрева с контролем температуры — пользователь покупает сам
- Ультразвуковая ванна 35-60 Вт, ~40 кГц — уже есть ("у отца")
- Точные весы 0.01г — уже есть у пользователя
- Термометр — куплен/уточняется
- Материал: свежие лепестки [PROVISIONAL: Rosa damascena]

**Важно:** реальных экспериментальных данных ЕЩЁ НЕТ (эксперимент не проведён). На сайте это должно
быть явно и честно помечено ("результаты появятся после защиты"), как и в самом TDR — не выдумывать
цифры.

**Ключевые источники (проверенные, с DOI, можно цитировать с уверенностью):**
- Buck & Axel, 1991, Cell — открытие генов обонятельных рецепторов
- Malnic et al., 2004, PNAS — ~388-390 функциональных генов OR у человека
- Dudareva et al., 2005, PNAS — пути биосинтеза терпенов (MVA/MEP) в цветочной ткани
- Thilakarathna et al., 2022, J Food Sci Technol — механизм акустической кавитации (обзор)
- Cadena-Cadena et al., 2025, BioTech — **главный ориентир методологии**: ультразвук перед
  дистилляцией дал +114% выхода масла (грейпфрут, 750Вт/20мин)
- PubChem: лимонен (CID 22311), гераниол (CID 637566), цитронеллол (CID 8842) — физ-хим свойства

**Источники с непроверенными цифрами (не приводить точные цифры без оговорки):**
- Abdel Samad et al., 2023 — заявленный рост "в 2514 раз" получен через суммирующую модель, не

- Состав масла розы (% цитронеллола/гераниола/нерола) и история Ибн Сины про дистилляцию розы —

## Концепция взаимодействия (решено)

**Scrollytelling-путешествие**, не плоский лендинг: камера физически "летит" через 3D-сцену по мере
скролла, а не просто fade-in блоков друг за другом. Пользователь на этом настоял явно после того как
увидел первую (плоскую) версию — счёл её "голой, бедной".

**Станции путешествия (в порядке прохождения):**
1. Hero — заголовок, имя, школа
2. Класс, где всё началось (мотивация) — пока самая слабая по визуалу станция, геометрия из простых
   кубов-парт, требует доработки
3. Внутри лаборатории (методология) — колба (стекло с преломлением), кольцо-штатив (золотой металл
   с отражениями через HDRI environment), процедурный цветок (лепестки+тычинки) рядом с колбой,
   драматичный луч света
4. На молекулярном уровне (академическая база) — шаро-стержневая модель молекулы со связями
5. Горизонт (статус проекта, таймлайн)

**Технические решения, которые РАБОТАЮТ и должны быть сохранены при пересборке:**
- Next.js 16 (App Router, Turbopack) + Tailwind v4 (CSS-based тема через `@theme inline`, без
  tailwind.config) + TypeScript
- React Three Fiber (`@react-three/fiber` v9, поддерживает React 19) + drei для 3D
- GSAP + ScrollTrigger для синхронизации скролла с камерой (не Framer Motion — выбрали одно, не
  дублировать)
- Drei `<Environment preset="studio" background={false}>` — даёт реалистичные отражения на
  стекле/металле бесплатно, без внешних HDRI-файлов
- `prefers-reduced-motion`: НЕ переключать на отдельную "плоскую" версию сайта целиком (это и была
  причина бага "на компьютере фона нет, на телефоне есть" — на компе была включена системная
  настройка анимации). Правильный подход: 3D-сцена остаётся всегда, под reduced-motion отключаются
  только декоративные бесконечные вращения (звёздное поле, вращение колбы/молекулы), а
  scroll-driven движение камеры остаётся — оно управляется пользователем, не автоплей
  - Прогресс скролла — через общий мутабельный объект (`journeyState`) + `useFrame`, БЕЗ React
    state на каждый тик скролла (важно для FPS)
  - При монтировании оверлея нужно сразу применить текущий прогресс (не ждать первого события
    скролла) — иначе Hero-текст невидим до первого пикселя скролла (был баг, исправлен)
- Деплой: Vercel, репозиторий на GitHub (`geotor228/projectschool`, приватный/публичный — публичный),
  автобэкап каждые ~30 минут пушит изменения → Vercel автоматически пересобирает
  - **Важный гочтча:** Root Directory в настройках Vercel-проекта должен быть `site` (сам Next.js
    проект лежит в подпапке `site/` репозитория, не в корне) — при неправильном значении
    (`site/public`) сборка "успешна", но отдаёт 404, framework не определяется
- Node.js, Python, git, gh CLI, Vercel CLI — все установлены на машине через winget

## Что пробовали и НЕ сработало (не повторять бездумно)

- **Image-to-3D через Higgsfield для конвертации фото цветов в 3D-модели**: 5 попыток (SAM 3D Meta,
  1 кредит за попытку) — все failed, даже с обрезанным одиночным цветком и пониженным
  detection_threshold. Гипотеза: стилизованные "стеклянные/хрустальные" фото с тонкими полупрозрачными
  лепестками не дают алгоритму распознать объём объекта. Модель Meshy image-to-3d стоит 30 кредитов
  (весь бюджет) — не пробовали, слишком дорого и рискованно после 5 фейлов на другой модели.
  Кредиты не списались ни разу (баланс всё ещё 10/10 на момент написания).
- **Готовые 3D-модели со Sketchfab**: пользователь скачал 2 модели (орхидея 51МБ, роза 375МБ) — обе
  оказались тяжёлыми фотограмметрическими сканами, непригодными для веба без агрессивной
  оптимизации (десятки МБ текстур, миллионы полигонов). Если возвращаться к этому пути — искать
  явно промаркированные "low-poly"/"game-ready" модели, не научные сканы.
- **Решение, которое сработало вместо этого:** процедурный цветок в коде (Three.js geometry:
  ShapeGeometry для лепестков, две "ярусные" группы лепестков + сферы-тычинки) — бесплатно, быстро,
  под полным контролем стиля/цвета.
